# 1. CSE 1101 — Computational Problem Solving

**Course Status:** CORE  
**Pre-requisite:** None

## Course Content

### Computational Thinking
- Scopes, evolution, and laws of modern computing systems
- Data representation
  - Data types
  - Encoding
  - Compression
- Logic building
  - Logical thinking
  - Propositional logic
- Problem solving
  - Defining a problem
  - Logical reasoning
  - Decomposition
  - Abstraction
- Algorithmic thinking
  - Name binding
  - Selection
  - Repetition
  - Modularization
- Solution modeling
  - Abstraction
  - Modeling
  - Data organization
  - Dealing with errors
  - Evaluation of a solution
- Computational limitations
  - Capacity measurement in computers
  - Benchmarking
  - Practicality and possibility of solutions

### Computing and Programming Fundamentals
- Introduction to computations
- Early history of computing devices
- Computers and major components
- Hardware
  - Processor
  - Memory
  - I/O devices
- Software
  - Operating systems
  - Application software
- Basic computer architecture
- Basic Information Technology
- The Internet
- Number systems
  - Binary
  - Octal
  - Hexadecimal
  - Binary arithmetic
- Basic programming concepts
- Program development stages
- Flowcharts
- Programming constructs
  - Data types
  - Operators
  - Expressions
  - Statements
  - Control statements
  - Functions
  - Arrays

## Course Objectives
- Understand computational thinking, modern computing systems, and data representation.
- Develop logical reasoning, abstraction, decomposition, and algorithmic thinking.
- Design and evaluate computational solutions using algorithms, modularization, and data organization.
- Analyze correctness, efficiency, and limitations through modeling, benchmarking, and performance evaluation.
- Develop problem-solving skills and professional attitudes for computational challenges.

**Course Status:** GED (Humanities and Social Sciences)  
**Pre-requisite:** None

## Course Content

### Grammar
- Tense
- Articles
- Prepositions
- Subject-verb agreement
- Clauses
- Conditionals
- Sentence structure

### Vocabulary Building
- Correct and precise diction
- Affixes
- Level of appropriateness
- Colloquial vs. standard English
- Informal vs. formal English

### Reading Skills
- Reading strategies
- Skimming
- Scanning
- Predicting
- Inferring
- Analyzing and interpreting texts
- Literary and non-literary texts
- Comprehension

### Writing Skills
- Sentences and sentence variety
- Generating sentences
- Clarity and correctness
- Linking sentences into paragraphs
- Paragraph writing
- Essay writing
- Report writing
- Formal and informal letters

### Listening and Note-Taking
- Listening to recorded texts
- Listening to lectures
- Taking useful notes

### Speaking Skills
- Personal identification
- Life at home
- Giving advice and opinions
- Instructions and directions
- Requests
- Complaints
- Apologies
- Describing people and places
- Narrating events

## Course Objectives
- Develop effective English communication for academic, professional, and engineering environments.
- Improve listening, speaking, reading, and writing through practical activities.
- Build confidence in interpersonal communication, teamwork, presentations, and professional correspondence.
